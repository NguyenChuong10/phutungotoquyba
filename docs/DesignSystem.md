# DESIGN SYSTEM & BRAND TOKENS - PHỤ TÙNG Ô TÔ Q.BA

## 🎨 BRAND DESIGN TOKENS

### 1. Bảng màu thương hiệu (Color Tokens)
- **Primary Brand Red**: `#D90429` (Tailwind Class `bg-brand`, `text-brand`, `border-brand`)
- **Accent Red**: `#FF0000` (dùng cho Highlight text, Slide title, Active Menu)
- **Dark Background**: `#111317` (Tailwind Class `bg-[#111317]`)
- **Deep Footer Dark**: `#0B0F19` (Tailwind Class `bg-[#0B0F19]`)
- **Success Green**: `#22C55E` (Nút Hotline Call `bg-green-500`)
- **Zalo Blue**: `#2563EB` (Nút Zalo `bg-blue-600`)

### 2. Typographic Hierarchy
- **Heading Extra Bold**: Montserrat / Outfit (`font-heading font-black uppercase`)
- **Body Regular**: Inter (`text-gray-700 leading-relaxed`)

### 3. Component Design Rules
- **Buttons**: Rounded pill (`rounded-full`) hoặc rounded card (`rounded-xl` / `rounded-2xl`), shadow glow (`shadow-[0_0_25px_rgba(217,4,41,0.4)]`).
- **Cards**: Border mảnh viền phát sáng khi hover (`border border-slate-200 hover:border-brand/40 hover:shadow-xl transition-all duration-300`).
